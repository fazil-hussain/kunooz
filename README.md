# Kunooz Al Asalah Building Maintenance L.L.C. — Website

Static company website (no database or build step).

## Structure

```
kunooz/
├── index.html        Home
├── about.html        About Us + company details
├── services.html     Services
├── blog.html         Articles list
├── contact.html      Contact + map
├── privacy.html      Privacy Policy
├── terms.html        Terms & Conditions
├── articles/         The 3 articles
├── css/style.css
├── js/main.js
├── images/           Logo and illustrations
├── favicon.ico / favicon.svg / apple-touch-icon.png   Browser and phone icons
└── reference/        Client-supplied screenshots (do not upload)
```

To publish, upload everything to `public_html` except `reference/` and `README.md`.
